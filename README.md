# Portafolio — Gibmyx Gomez

Sitio de presentación personal construido con Next.js 16, React 19 y Tailwind CSS 4.
Estilo minimalista en blanco, negro y azul, con modo claro/oscuro.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Editar el contenido

Todo el contenido (perfil, experiencia, proyectos, habilidades, formación y contacto)
vive en `lib/profile.ts`. Edita ese archivo y la página se actualiza sola.

El CV descargable está en `public/cv-gibmyx-gomez.pdf`; reemplázalo para actualizarlo.

## Producción

```bash
npm run build
npm start
```
